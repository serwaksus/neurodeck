## Окружение и процесс (ВАЖНО для новой сессии)

- **Маунт ~/vps мёртв** (умер 28.09). Рабочая копия: `~/work/neurodeck` (rsync с VPS в начале работы). Правки → `rsync -a файл vps:/путь/`; git/тесты — по `ssh vps` в /root/neurodeck. Не запускать параллельные прогоны тестов (порт 8099 конфликтует; в CI-цепочке мешали друг другу — parity ловила фантомный P2).
- **pkill -f "serve.cjs"** убивает собственную ssh-сессию (паттерн в cmd) — юзать `pkill -f "[s]erve.cjs"`.
- git push с VPS работает (credential.helper=store, ~/.git-credentials).
- Деплой = push в main → GitHub Actions → Pages. Бампать **?v= в index.html И VERSION в sw.js синхронно** (сейчас v79/nd-shell-v79).
- Установлены gamedev-скиллы в `~/.zcode/skills/` (game-ui-ux, game-feel, create-game-assets, performance-optimization, game-assets-enhancer). Ключевые уроки применены: свет (1 источник сверху-слева, контровые блики, диапазон значений), лайт-грейд панелей; **плоский вектор = дёшево, настоящий арт = game-icons.net**.
- Иконки: инлайн-SVG `<path fill="currentColor">` из карты ICON_PATHS (app.js) через artIconHtml(name, cls); эмодзи-фолбэк. НЕ использовать CSS-mask с url() (резолв от CSS-файла + парсинг-грабли).
