## Что построено (полная архитектура)

### Концепция
HoMM3-подобная стратегия поверх трекера привычек:
- Выполняешь реальные привычки (карточки) → получаешь золото 💰
- Захватываешь 20 твердыней армиями (4 провинции × 5)
- Строишь 20 типов зданий (жилища существ, экономика, оборона, особые)
- Нанимаешь 7 тиров существ (недельный прирост)
- Отбиваешь воскресные осады (эскалация ×1.15^неделя + Гнев)
- Следишь за коррапшном построек (без содержания ветшают)

### Три уровня геймплея
- **День**: карточки (+1💰/−1💰) → задачи (сундук/призрак) → налоги твердынь
- **Неделя**: воскресная осада (гарнизон vs варвары), пул найма
- **Месяц+**: 20 твердыней, 7 тиров, кампания ~42 недели (средний игрок)

### Технический стек
- Vanilla JS (app.js 2800+ строк), без фреймворков
- PixiJS удалён (была боёвка — вырезана при пивоте)
- Хранилище: localStorage + IndexedDB + Telegram CloudStorage (схема v8)
- Шрифты: Cinzel (display) + Crimson Text (body), Google Fonts
- Спрайты: Kenney CC0 (isometric_buildings, medieval_rts)
- Бот: node/polling.js, systemd neurodeck-bot.service, /opt/neurodeck-bot
- Telegram Mini App: t.me/NeuroDeckBot/neurodeck
