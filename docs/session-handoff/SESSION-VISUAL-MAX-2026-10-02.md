## Честные метрики и ограничения

- На первом мобильном экране (390×844) первая карточка колоды видна не полностью; цель плана «≥ 3 карточки» **не достигнута**.
- Бюджеты: `style.css` ≈ 182/200 КБ, `app.js` ≈ 484/520 КБ.
- Локальные визуальные снимки в `tests/e2e/snapshots/` в этой песочнице не совпадают (другой Chromium). Эталоны для CI должны появиться в `tests/e2e/snapshots-ci/` через ручной запуск workflow с `update_visual`; до этого визуальный job остаётся `continue-on-error`.
- **Не проверено:** job `visual` в контейнере и whitelist-деплой Pages ни разу не запускались в GitHub Actions (из песочницы нет доступа к github.io и нет CI-прогона). Владельцу нужно: Settings → Pages → Source = GitHub Actions; запустить workflow; просмотреть первые CI-снимки глазами.
- Проверка на физических устройствах (iOS/Android в Telegram, слабый Android) **не проводилась**; сертификация не заявляется.
- Геймплей, формулы и схема сейва не менялись.
