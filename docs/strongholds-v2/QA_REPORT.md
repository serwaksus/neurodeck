## Найденные дефекты

### BUG-1 (средний): битые иконки захваченных твердынь в сетке — дубль `shSprite`, 404-шторм в консоли

**Симптом.** В сетке «Твердынь» у каждой захваченной твердыни вместо иконки текст «undefined»; каждая перерисовка сетки генерирует до 20 ошибок `Failed to load resource: ... 404`. За один приёмочный прогон — **273 ошибки консоли** (гейт «0 ошибок консоли» не выполняется именно из-за этого).

**Шаги воспроизведения:**
1. Новый игрок → старт-колода → онбординг.
2. Построить Ж1 в Сендер-Хуторе, найм 14×Т1, штурм sh01 → захват.
3. Открыть вкладку «Твердыни»: карточка sh01 в статусе owned показывает иконку «undefined»; в консоли `GET http://<host>/0 → 404`.

**Корневая причина.** Два объявления функции с одним именем в одной области видимости `js/app.js`:
- `app.js:1608` — `function shSprite(idx)` (индексный вариант: `img/tract/regionNN.png` для #1–11, эмодзи для #12–20 — так и задумано SPEC §1 «иконки #1–11 наследуют `icon`/`img` REGIONS»);
- `app.js:1709` — `function shSprite(path, emoji)` (путевой вариант: `<img src="…" onerror="this.outerHTML='…'">`).

Оба — function declaration в одном скоупе: **последнее объявление побеждает для всех вызовов**. Единственный числовой вызов — сетка, `app.js:1689`: `shSprite(i)` → рендерится `<img src="0">` (число как строка) → 404 → `onerror` пишет `outerHTML='undefined'` (emoji-аргумент не передан). Панельные вызовы (`app.js:1725, 1740, 1755`) передают строковый путь + эмодзи и работают корректно — поэтому в панели твердыни всё цело, ломается только сетка.

**Доказательство [F].** Серверная сторона прогона залогировала 273 запроса с 404 по путям `/0`, `/1`, … `/12` — ровно индексы захваченных твердынь всех блоков прогона; ассерт 1.4 нашёл owned-иконку с текстом «undefined». Файлы `img/tract/region01..11.png` существуют — без дубля сетка показывала бы спрайты.

**Влияние.** Визуальный дефект главной сетки прогресса (все захваченные твердыни — «undefined»); шум консоли (273 ошибки за сессию, растёт с числом захватов и перерисовок); иконки #1–11 из SPEC §1 фактически не показываются никогда.

**Рекомендация dev (не применялась — QA продукт не правит):** удалить одно из объявлений. Минимальный диф: убрать путевой вариант (1709) и восстановить в 1709-й позиции индексный, а панельные вызовы перевести на `shSpriteImg(path, emoji)`-обёртку; либо убрать индексный (1608) и звать из сетки `shSprite('img/tract/region' + String(i+1).padStart(2,'0') + '.png', STRONGHOLDS[i].icon)` с веткой эмодзи для `i >= 11`.
