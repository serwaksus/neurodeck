## 5. Находки

### FINDING-1 · P1 — editCardModal и syncModal невидимы и некликабельны пользователю (перекрыты контентом)
- **Где:** `index.html:364` (`#editCardModal`) и `index.html:525` (`#syncModal`) — единственные модалки, вложенные в `.app-wrap` (строка 17); остальные (`starterDeck`, `task`, `weeklyReport`, `season`, `siegeReport`, `confirm`) — прямые дети `<body>` и работают. CSS: `.app-wrap { position: fixed }` (style.css:27) создаёт stacking context в Chromium, `.modal-overlay { z-index: 400 }` (style.css:442) заперт внутри него и проигрывает `#shakeWrap { z-index: 5 }` с контентом.
- **Ожидалось:** открытая модалка редактора/синхронизации видна поверх контента и кликабельна.
- **Фактически:** `display:flex`, `opacity:1`, rect 390×844 — но `elementFromPoint` в центре возвращает карточку (`SPAN.card-adaptation-tag`), клик по «💾 Сохранить» перехватывается кнопкой карточки под модалкой (воспроизведено: «button.card-complete-btn … intercepts pointer events»), скриншот показывает колоду **без модалки** — в т.ч. сразу после ранг-апа (`shot04_E2_rankup_edit_modal.png`: ранг CC присвоен, модалки не видно).
- **Влияние:** игрок не может редактировать/сохранять карточки, не видит экран эволюции после ранг-апа (ядро фичи сессии), недоступна синхронизация/настройки. Автоплейтест обошёл программными кликами через штатный обработчик — это костыль теста, не решение для пользователей.
- **Доказательства:** `/tmp/opencode/qa-full/shot04_E2_rankup_edit_modal.png`, `/tmp/opencode/qa-full/debug_edit_modal.png`, лог перехвата клика (debug-d2).

### FINDING-2 · P1 — выполненные дневные квесты сбрасываются после F5 (потеря состояния + фарм награды)
- **Где:** `js/storage.js:799` (applySyncData восстанавливает `dailyQuests.day/.done/.progress`, но **не** `quests`) + `js/app.js:1886-1888` (renderStrongholds пересоздаёт доску с `done:{}, progress:{}`, если `quests` пуст).

- **Влияние:** тем же днём квест можно выполнить и забрать награду заново (+15…+25 💰 × 3 квеста за каждый F5) — экономический эксплойт и потеря прогресса игрока.

### FINDING-3 · P2 — кнопка «Новая игра» отсутствует в UI (мёртвая точка входа)
- **Где:** обработчик `case 'new-game-keep-cards'` (app.js:138) существует, но элемента с этим `data-action` нет ни в `index.html`, ни в рендере.

### FINDING-4 · P2 — malformed HTML в sync-модалке: кнопка «🗑 Сброс» исчезает из DOM
- **Где:** `index.html:685-702` — блок `<div class="sync-section">…</div>` вклеен **внутрь открывающего тега** `<button class="demo-btn" … data-action="full-wipe-all">`.
- **Шаг:** Q3. **Фактически:** `[data-action="full-wipe-all"]` в DOM отсутствует (парсер проглатывает кнопку; текст «🗑 🗑 Сброс» и атрибуты выпадают в контент). Чипы «Напоминания» при этом рендерятся (3 шт).
- **Влияние:** полный вайп (`fullWipeAll`) недостижим из UI; разметка секции «Напоминания» визуально вложена в чужой контекст.

### FINDING-5 · P3 — на каждой карточке рендерится текст «undefined»

- **Фактически:** в каждой `.card` висит текстовый узел «undefined» (после строки «Выполнено: N · 🔥 N»); видно на скриншотах колоды. Косметика, данных не теряет.

### FINDING-6 · P3 — расхождения чек-листа с дизайном (не дефекты продукта)
