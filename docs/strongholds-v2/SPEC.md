## 2. Каталог построек (20)

Категории (ADR §4): 7 жилищ / 5 эконом / 4 оборона / 4 особых. В твердыне доступно подмножество: постройка видна, если «мин. твердыня» ≤ номер твердыни, строится — если выполнены пререквизиты и есть свободный слот. Одна постройка каждого типа на твердыню; одинаковые постройки в разных твердынях суммируются (приросты, эффекты, содержание). Эффект масштабируется стадией коррапшн (§6): Целое ×1.0, Обветшало ×0.5, Руина ×0. Новая постройка иммунна к деградации 7 дней (§6).

## 4. Штурм (auto-resolve)

Единственный способ захвата — армией (ADR §1). Кнопка у фронтовой незахваченной твердыни; лимит 1 штурм в сутки. Тактического боя нет: расчёт + отчёт о потерях.

```
armyPower = Σ (count_тира × сила_тира)               // полевая армия
atk       = round(armyPower × (1 + 0.02 × str))      // ⚔ командирская (§7)
defN      = garrison + defense                       // нейтралы, таблица §1
ratio     = atk / defN
```

- **ratio > 1 → победа, захват.** Налог идёт со следующего дня; базовая оборона твердыни теперь служит игроку (§5); нейтральный гарнизон исчезает; фронт сдвигается (`frontSince` = сегодня). Attrition при победе (тоже ADR §1):
  `attrition% = clamp(0.30 / ratio; 0.08; 0.30) × (1 − min(0.50; 0.01 × agi)) × (П2 ? 0.8 : 1)`
  Потери: по каждой стопе `floor(count × attrition%)`. Награда: +150 XP (множится 🧠, §7). [BALANCE: G2] формула attrition, клампы 0.08–0.30.
- **ratio ≤ 1 → поражение (отступление).** Потери `10 + rand(0..20)%` (равномерно, итого 10–30% — ADR §1), по каждой стопе `floor(count × loss%)`. Армия остаётся полевой; повторный штурм — на следующий день.
- Полный разгром невозможен: `floor` оставляет ≥1 юнита в непустой стопе.

Проверка масштаба: 10 ополченцев (power 20), str 5 → atk 22; твердыня 1 (defN 15) → ratio 1.47 → attrition 20.4% → потеряно 2. Первый захват достижим на 2–3-й день (найм 10×30 = 300💰). [BALANCE: G3] сценарии «первая неделя нового игрока» и «мигрант с regions=10» (§9).

## 5. Воскресная осада

Каждое воскресенье 23:00 МСК (совместно с недельным сбросом), если захвачена хотя бы одна твердыня (ADR §6).

```
wrath      = min(10; 2×активные_призраки_задач + пропуски_карточек_за_неделю + проваленные_задачи_за_неделю)
W          = полных недель с захвата фронтовой (последней захваченной) твердыни; кап W = 12
siegePower = round(Итого_обороны_фронта × 0.6 × 1.15^W × (1 + 0.08 × wrath))
```

- **Таргет — фронт (последние 1–3 захваченные).** Основная цель — последняя захваченная. Если `siegePower > 1.5 × garDef` цели — прорыв: осада прокатывается по 2-й и 3-й из последних захваченных, сила каждого следующего удара ×0.85. Максимум 3 твердынь за ночь. [BALANCE: G2] коэффициенты 0.6 / 1.15^W / кап 12 / 0.08×wrath / кап wrath=10 / порог 1.5 / затухание 0.85.
- **Защита твердыни игрока:** `garDef = Итого_обороны (база §1) + Σ оборонных построек + round(гарнизонPower × (1 + 0.02 × end))`. ГарнизонPower = сила существ, оставленных в этой твердыне. Перевод армия↔гарнизон бесплатный; гарнизон не участвует в штурмах — главный компромисс игрока.
- **Отбито (garDef ≥ siegePower):** «бьёт даже при победе» (ADR §6) — гарнизон теряет 15% (`floor` по каждой стопе); награда +100 XP × номер провинции. [BALANCE] потери 15%, награда XP.
- **Падение (garDef < siegePower):** твердыня теряется → нейтралы по таблице §1; постройки остаются, но все переводятся в «Руину» (§6); гарнизон уничтожен полностью; `frontSince` сбрасывается на дату осады (следующее воскресенье не каскадирует).
- Осада — главный поглотитель золота и юнитов; дисциплина недели (мало пропусков/призраков) напрямую снижает siegePower.

## 6. Коррапшн

Каждую ночь в 23:00 МСК (checkDailyReset) списывается содержание: `upkeep = Σ содержание всех построек` (иммунные тоже платят). Порядок списаний дня: upkeep первым.

- **Казна покрыла upkeep** → постройки в стадии ниже «Целое» поднимаются на 1 ступень (Руина → Обветшало → Целое), `debtDays = 0`. [BALANCE] темп восстановления 1 ступень/день.
- **Казна не покрыла** (дефицит): золото = 0, `debtDays += 1`. Стадии (ADR §5):
  - `debtDays ≤ grace` → все Целое (без изменений);
  - `grace < debtDays ≤ grace + step` → Обветшало (эффекты ×0.5);
  - `debtDays > grace + step` → Руина (эффекты ×0, содержание не списывается — руина «не ест»).
  где `grace = 2 + floor(wil / 20)` дней (🧘, §7), `step = 2` дня на ступень (П3 «Собор Порядка» → `step = 4`). [BALANCE] grace-формула, step, правило «руина не ест».
- **Восстановление:** любой оплаченный день поднимает каждую руинную/обветшалую постройку на 1 ступень (см. п.1). Постройки не сносятся никогда — коррапшн обратим.
- **Иммунитет нового:** постройка не деградирует 7 дней с момента постройки (ADR §5); содержание при этом списается штатно.
- **Оффлайн-докрутка:** при возврате в приложение докручиваются ночные списания/стадии и последняя воскресная осада, но не более 7 суток событий; всё старше схлопывается в 7-й день (ADR §5). Мигрант/вернувшийся не может потерять больше одной недели коррапшна. [BALANCE] сценарий «вернулся через 30 дней».
- UI: у каждой постройки бейдж стадии; сводка «содержание/день» на панели казны рядом с доходом.

## 7. Атрибуты-командирские

Очки не меняются: ранг-ап карточки → +1 в пул стата; 5 пула → +1 к атрибуту (макс 100); уровень → +1 ко всем шести. Меняются РОЛИ атрибутов (ADR §2) — старые боевые эффекты (урон боссу, крит, HP) упразднены вместе с souls-петлёй (v49):

| Атрибут | Роль v2 (командирская) | Формула | Кап |
|---------|------------------------|---------|-----|
| ⚔ str | Атака армий | `atk = armyPower × (1 + 0.02 × str)` | нет (линейно) |
| 🛡 end | Оборона гарнизона | `garDef-компонент = гарнизонPower × (1 + 0.02 × end)` | нет |
| 🎭 cha | Скидка найма | `cost = ceil(base × (1 − min(0.30; 0.005 × cha)))` | −30% (cha 60) |
| 🧘 wil | Сопротивление коррапшну | `grace = 2 + floor(wil / 20)` | +7 дней (wil 100→grace 7... кап grace 7) |
| 🧠 int | Опыт командира | `xp × (1 + (int − 3) × 0.01)` (без изменений, §4.3 док.) | нет |
| ⚡ agi | Манёвр (attrition) | `attrition × (1 − min(0.50; 0.01 × agi))` | −50% (agi 50) |

Стриминговый эффект: игрок, качавший «боевые» статы, получает боевого командира; раскачка — через те же карточки и цели (без нового UI, вкладка Герой).
[BALANCE] формулы cap'ов cha/wil/agi; вклад str/end на поздних стадиях (при armyPower 10k+ прибавка 2%/очко может уйти в шум).

```
wrath         = min(10; 2×призраки + пропуски_7д + провалы_7д)
siegePower    = round(Итого_обороны_фронта × 0.6 × 1.15^W × (1 + 0.08×wrath)), W ≤ 12
debt stages   = grace=2+floor(wil/20); step=2 (П3: 4); Целое/Обветшало(−50%)/Руина(0%)
```

## 9. Миграция v7 → v8

Схема v8 (ADR §10) — новые поля snapshot:
```json
{
  "schemaVersion": 8,
  "hero": { "...": "gold сохраняется как есть" },
  "strongholds": [
    { "idx": 0, "captured": true, "buildings": {}, "garrison": {} },
    { "idx": 1, "captured": false, "buildings": {}, "garrison": {} }
  ],
  "army": { "t1": 0, "t2": 0, "t3": 0, "t4": 0, "t5": 0, "t6": 0, "t7": 0 },
  "siege": { "weekCount": 0, "frontSince": null, "lastResult": null },
  "corruption": { "debtDays": 0 }
}
```

Шаги миграции:
1. `schemaVersion: 7 → 8`.
2. `tractState.regions → captured`: для всех `i = 0..tractState.regions` → `strongholds[i].captured = true` (семантика v1 «владеет i ≤ regions», js/app.js:1407, 1464). Налоги #1–11 = `rev` REGIONS 1:1 → доход мигранта не меняется (247💰/день при полном тракте).
3. `hero.gold` сохраняется без пересчёта (ADR §10: «золото цело»).
4. `army = {t1..t7: 0}` — армия пуста (ADR §10); первый юнит — найм Т1 в Сендер-Хуторе (если captured ≥ 1) или штурм с нуля невозможен → подсказка «постройте Ж1» (Ж1 доступен с твердыни 1; мигранту с regions=0 Ж1 строится сразу).
5. `siege = {weekCount: 0, frontSince: null, lastResult: null}`; первая осада — ближайшее воскресенье.
6. Незавершённая стройка v1 (`tractState.building`): отменяется, игроку возвращается `floor(0.5 × cost)` региона. [BALANCE] коэффициент возврата.
7. Легаси-снос (ADR §9): `escapeProgress`, `ROOMS`/`ROOM_THEMES`, `ESCAPE_MAX`, `ROOMS_STEP` и вкладка «Карты» удаляются; прогресс = `captured.length`. Поля souls-эпохи (`bossHp`, `bossStage`, `chimeraShield`, `estus`, …) не переносятся.
8. Guard'ы: `regions` вне 0..10 → clamp; отсутствие `tractState` → сильholds все `captured=false`; повторная миграция запрещена (`schemaVersion >= 8` → skip).
9. v7-поля `tasks`, `taskIdCounter`, `forged`, `stats`, `inventory`, `xpHistory` переносятся без изменений.

Совместимость с ADR-0001: §1 штурм армиями + attrition (§4), §2 атрибуты-командирские (§7), §3 вкладка «Твердыни» + 4×5 (§1), §4 каталог 7/5/4/4 (§2), §5 коррапшн-стадии (§6), §6 воскресная осада с Гневом (§5), §7 тиров существ с недельным приростом (§3), §8 конвейер (шапка, §8), §9 снос легаси (шаг 7), §10 схема v8 (шаги 1–5). Спека не вводит систем вне ADR: ходьбы героя нет, тактических боёв нет, ресурсов кроме золота нет.
