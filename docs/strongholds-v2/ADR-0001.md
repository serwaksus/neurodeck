# ADR-0001: «Твердыни v2» — конституция (binding)

Статус: ПРИНЯТО пользователем 2026-09-13. Нарушать нельзя.

1. Захват твердынь — армиями (auto-resolve armyPower vs garrisonPower+defense). Поражение = отступление с потерями 10–30% (рандом). Attrition при победе тоже.
2. Атрибуты → командирские: ⚔ атака, 🛡 оборона гарнизона, 🎭 скидка найма, 🧘 сопротивление коррапшну, 🧠 XP, ⚡ манёвр (attrition).
3. Вкладка «Твердыни» (не «Тракт»): выбор замка/аванпоста → построики/найм выбранного. 20 твердынь (4 провинции × 5).
4. Каталог 20 построек: 7 жилищ / 5 эконом / 4 оборона / 4 особых; в твердыне — подмножество.
5. Коррапшн: содержание/день; без золота: Целое → Обветшало (−50%) → Руина (0%); grace 2 дня; оффлайн-докрутка кап 7 дней; новое иммунно 1 неделю.
6. Воскресная осада: ×1.15^неделя + Гнев (призраки/пропуски); таргет — фронт (последние 1–3); бьёт даже при победе.
7. Существа: 7 тиров, недельный прирост из жилищ.
8. Конвейер: designer → balance (G1–G3) → dev (v8) → art (CC0 Kenney) → qa (плейтест «месяц королевства»). Арт готовый, не генерация.
9. Снос легаси: вкладка Карты (ROOMS/escapeProgress/ESCAPE_MAX) удаляется; прогресс = захваченные твердыни.
10. Схема v8: strongholds[], army{}, siege{}, corruption; миграция v7→v8 (regions→captured, золото цело).

## Патч 1 (2026-09-13, решение продюсера по эскалации баланса)

11. Кривая налогов твердынь — эндгеймовая: поздние твердыни платят кратно больше ранних; доход карточек/задач v1 не инфлируется (паритет binding).
12. Кап силы воскресной осады — по прогрессу захвата, не по календарю: застой фронта не эскалирует осаду.
13. Анти-тупик: при потере ВСЕХ твердынь фронт сбрасывается к твердыне №1 с базовой обороной нейтралов (без накопления) — путь возврата существует всегда.
