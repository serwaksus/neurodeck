# Кампания 3.0 — «Герои 3 × Total War» для геймификации жизни

## Context

Сейчас стратегический слой NeuroDeck (20 твердынь, общая армия, штурм раз в день, воскресная осада) слабо связан с реальной жизнью: привычка даёт +1 💰, героя на карте нет, ранги карточек и уровень героя почти не влияют на королевство, враги статичны (нейтралы с фиксированной силой, «Глорх» — просто число). Хуже того, честно отметить пропуск невыгодно: молчание наказывается слабее, чем явный пропуск. Плюс есть дыры для фарма (безлимит задач, порог мастерства 2, награда квеста из DOM, флаги дня вне сейва).

Цель — новая кампания, где **реальные дела — единственный двигатель стратегии**: день = ход, очки движения героев приходят только из выполненных дел, враги — фракции твоих же пороков, которые растут от срывов и слабеют от дисциплины.

### Решения владельца (зафиксированы)
| Вопрос | Решение |
|---|---|
| Ход | день = ход; очки движения (ОД) героев — из дел этого дня; понедельник — прирост существ |
| Герои | 4 героя-сферы: **Тело** (Сила/Стойкость/Ловкость), **Разум** (Интеллект), **Дух** (Воля), **Связи** (Харизма); маппинг атрибута автоматический |
| Враги | ИИ-фракции пороков, ходят армиями и захватывают земли |
| Масштаб | новая кампания 3.0, старые сейвы → «наследие» |
| Бои | авторасчёт + выбор 1 из 3 тактических карт |
| Ресурсы | золото + Сталь (Тело), Знания (Разум), Воля (Дух), Влияние (Связи) |
| Честность | неотмеченное = пропуск; честный пропуск = половина штрафа; отдых 1–2 дня/нед. объявляется **заранее** |
| Время | 10–15 мин в день в стратегии |
| Города | **можно потерять** (как в Total War) — с защитой от «спирали смерти» |
| Финал | сезоны-карты по ~12 недель; победа = пали все логова; новая карта с наследием |

## 1. Игровой цикл

**Ход дня** (MSK-сутки, закрывается в `checkDailyReset`, `js/app.js:5489`):
1. **Дела → ОД и ресурсы.** Привычка сферы S: +1 ОД герою S и +1 ресурс S; задача: +2 ОД. Бонус ранга карточки: C/B +0, A/S +1, SS/SSS +2. Кап героя 6 ОД/день; 1 ОД переносится. Золото — от городов и шахт, не от дел.
2. **Действия на карте:** шаг по ребру 1 ОД (болото/горы 2), вход на шахту/объект — захват, вход на вражеский узел — бой, найм и стройка в городе (без ОД, но с ресурсами). Автопуть и кнопка «Закончить ход».
3. **Итоги дня:** неотмеченная привычка = 1 «тень», честный пропуск = 0.5, объявленный отдых = 0, просроченная задача = 1 тень Прокрастинации. Тени распределяются по фракциям.
4. **Дрейф пороков:** гарнизоны фракций +⌊тени×k⌋; при ≥3 тенях фракция может занять 1 соседнюю нейтральную шахту.

**Большой ход недели** (вс→пн, заменяет `runWeeklySiege` `js/app.js:3080`): прирост в городах (у каждого свои жилища), ходы фракций (≤1 атака/захват каждой), сводка недели + сообщение бота.

**Перемирие-обет:** с фракцией на неделю ценой реального обета («7/7 дней привычки X»). Нарушил — фракция +50% к следующему ходу. Не стоит ни ресурсов, ни ОД.

**Лазарет:** до 7 дней раз в сезон (болезнь/отпуск) — пороки замирают, тени не начисляются.

## 2. Карта 3.0 (сезон ≈ 12 недель)

- Неориентированный граф из ~36 узлов, 4 региона × 9 (телефон: узлы, не гекс-сетка). Позиции героев — индекс узла.
- **Города (4, по сфере):** Кузня/Тело, Академия/Разум, Монастырь/Дух, Ярмарка/Связи. Своё дерево из 6–8 зданий, 3 жилища (T1/T3/T5) со своим недельным приростом. Цена: золото + ресурс своей сферы; элита — ещё ресурс соседней сферы (нельзя прокачаться одной сферой).
- **Шахты (8):** +1 ресурс/день. **Объекты (8):** святилище (навык за 3 дня подряд дел сферы), сокровищница (разово), обелиск (снимает туман + реальный челлендж в духе нынешних боссов `bossProgressTick` `js/app.js:2168`).
- **Логова пороков (4–6):** финальные цели сезона.
- **Туман:** радиус 1 от героев и владений + открытые обелиски.
- Отряды 7 тиров переиспользуют `UNIT_TIERS` (`js/stronghold-data.js:53`); армия привязана к герою, у города отдельный гарнизон.

## 3. Фракции пороков (ИИ)

| Фракция | Растёт от | Поведение |
|---|---|---|
| Лень | пропущенных привычек | медленно, захватывает шахты Стали |
| Прокрастинация | просроченных задач и призраков | копит, крупный удар в воскресенье |
| Рассеянность | ≥2 сфер без дел ≥3 дней | бьёт по самой запущенной сфере, наводит туман |
| Уныние (опц., Глорх как лидер) | серии ≥3 дней без дел | осаждает Монастырь |

- Сила `S = base × (1 + 0.15 × тени за скользящие 7 дней)`, кап ×2.5 — старые срывы «выветриваются».
- ИИ детерминированный (сид = день + фракция): ответить на угрозу → атаковать слабейший соседний узел при S/def > 1.2 → занять нейтральный → укрепиться.
- **Как ослабить:** стрик ≥7 → −10% силы связанной фракции; ранг-ап карточки → −гарнизон ближайшего логова; неделя без теней → фракция теряет крайний узел.
- **Потеря городов (решение владельца) + защита:** город теряется только после осады ≥2 недельных ходов; последний город сферы — «столица», её можно осадить (прирост и доход ↓), но не взять; потерянный город при отбивании первые 7 дней имеет −30% обороны («освобождение»); резиновая лента: при контроле <30% карты ИИ −25%; «Возвращение»: первый день с делами после ≥3 пустых — ×2 ОД; в сводке не больше одного негативного события на экран.

## 4. Бой

`ratio = армия × (1 + навык героя + тактика) / оборона` → существующий `assaultOutcome` (`js/stronghold-model.js:83`), победа при ratio > 1, потери как сейчас. Перед боем 3 тактические карты из пула: навыки героя («Натиск» +15% атаки, «Строй» ×0.7 потерь…) и топ-3 реальных карточки сферы — их ранг задаёт силу эффекта (C 5% … SSS 25%). Прогноз до/после выбора. RNG только сидированный.

## 5. Фаза 0 — обязательные анти-абуз фиксы (ОД идут только из дел)

1. Тишина vs честность: неотмеченное в конце дня = полный штраф; явный пропуск (`failCard` `js/app.js:850`) — половина, стрик сохраняется за щит.
2. Кап: ОД/ресурсы максимум с 5 задач в день, сверх — только XP.
3. Порог мастерства ≥5 и только вверх (`js/app.js:816` + форма правки).
4. Награда ежедневного квеста — из `DQ_POOL` по id, не из `data-reward` DOM (`completeDailyQuest` `js/app.js:2883`).
5. Флаги дня (`nd_dailgoaldone_*`, `neurodeck_reroll_day`, `nd_pomodoro_*`) — в сейв и санитизацию `js/state-guards.js`.
6. Одна карточка даёт ОД не чаще 1 раза в день.

## 6. Наследие (сейв v14 → v15)

Не 1:1, а бонусами (объект `c3Legacy`, считается один раз): карточки, ранги, XP, атрибуты — как есть (это реальная жизнь); стартовые уровни героев из суммы атрибутов сферы; каждые 5 захваченных твердынь 2.0 → +1 стартовое здание (макс. 3); побеждённые боссы → навыки/реликвии; сезоны/трон → стартовое золото (≤2000); 10% армии → стартовые T1–T3; 1 «доктрина-наследие». Состояние 2.0 хранится read-only одну версию для отката, удаляется в v16. Миграции — через `MIGRATIONS`/`migrateSyncData` (`js/storage.js:113, :271`).

- Сложность против 10–15 минут: автопуть, «закончить ход», один экран сводки.

  Отклонения от дизайна, принятые в Ф1 (в основном дизайне — без изменений до решения владельца):
  1. Прирост существ зависит от дел недели: `GROW × (0.25 + 0.75 × min(1, ОД недели / 28))` — без этого армия росла бы сама и дисциплина почти не влияла на исход (калибровка симулятором).
  2. Сила логова = базовая оборона × `min(2.5, 1 + 0.15 × тени за 7 дней)`; отдельного «роста гарнизона от теней» нет (один понятный множитель).
  3. Набег Лени — раз в неделю на ближайший к логову узел игрока (кроме города и узла, где стоит герой): `S = оборона логова × множитель × 0.15` против `40 + 20 × закалка`; сталь (из дел Тела и шахты) — сток через «Закалку».
  4. Задачи не имеют сферы: в Ф1 дают 2 ОД единственному герою (Тело); в Ф2 нужна привязка задачи к сфере (поле при создании).
  5. Потери в бою округляются вверх (малые стопы платят за бой).
  6. Состояние `c3` — необязательный ключ сейва, схема остаётся v14; при выключенном флаге ключа в сейве нет.
  7. Бюджет прекэша JS+CSS репиннут 940 → 1000 КБ (новые модули ≈ 40 КБ; `tests/perf.test.js`).
- **Не сделано (по плану):** Ф2 (4 героя, 36 узлов, 5 ресурсов), Ф3 (ИИ фракций, потеря городов), Ф4 (тактика), Ф5 (наследие/миграция v15), Ф6.
