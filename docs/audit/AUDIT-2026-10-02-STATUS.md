## P0 — разд. 1 (влито в `main`)

| № | Проблема | Исправление |
|---|----------|-------------|
| 1.1 | «Клятва на крови» уничтожала карточку игрока даже при соблюдённой клятве | `checkBloodOathDaily` сверяет `lastCompletedDay` со **вчерашним** днём (раньше — с `lastDayReset`, к тому моменту уже равным сегодняшнему) |
| 1.2 | Устройство со старым сейвом молча затирало более новый прогресс в облаке | «База синхронизации» `nd_cloud_base` (id версии облака, которую устройство последний раз писало/читало). Если облако менял не этот клиент — автопуш откладывается и показывается диалог «☁ Облако изменилось» (Взять облако / Оставить моё). Загрузочный ре-сейв больше не «освежает» метку времени |
| 1.3 | Старт-колода на чистом устройстве затирала облачный сейв; SDK Telegram грузился `async` | SDK — синхронный `<script>` перед скриптами приложения; диалог восстановления из облака и старт-колода взаимоисключаются (`__ndRecoveryOpen`); fail-safe 5 с не снимает блокировку, пока диалог открыт |
| 1.4 | Эндгейм 20/20: вкладка «Твердыни» падала с пятницы по воскресенье (`STRONGHOLDS[-1].prov`) | Гвард `frontIdx() >= 0` в блоке осадной тревоги |
| 1.5 | XSS через импорт сейва (`#base64`, файл `.ndsync`, облако) | Санитайзеры импорта: числовые `stats`, `xpHistory` только `YYYY-MM-DD`, uid инвентаря `[A-Za-z0-9_-]{1,40}` + каталог артефактов, `dailyQuests`/`bloodOath`/`dailyEvent` пересобираются из каталогов. CSP через `<meta>`: `script-src 'self' 'sha256-…' https://telegram.org`, без `unsafe-inline`/`unsafe-eval`, `connect-src 'self'`. Убраны inline-обработчики `onerror=` |

Тех. мелочи: пины `?v=` → 103 (15 мест в `index.html`), `VERSION` в `sw.js` → `nd-shell-v103`; `dungeonConfirm` возвращает подписи кнопок; `#goalSteps` навешивается из JS.
