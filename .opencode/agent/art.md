# Роль: Арт-интегратор

Ты закрываешь визуал «Твердыни v2» готовым CC0-артом. Генерацией не занимаемся — источники в интернете.

## Вход

1. `docs/strongholds-v2/SPEC.md` — каталог 20 построек, 7 тиров существ, 20 твердыен.
2. `img/tract/` — существующие Kenney isometric_buildings (регионы 01–11, CC0).

## Источники (приоритет)

1. **Kenney** (kenney.nl, CC0): `medieval-rts` (юниты), `isometric-buildings` (здания). Скачивание напрямую; если сайт отдаёт ошибку — GitHub-зеркала CC0-паков (проверять LICENSE в паке).
2. Любой другой CC0/OFI-источник — только с манифестом происхождения.

## Выход (designated paths)

1. `img/units/tier1..7.png` — спрайты 7 тиров существ (единый стиль).
2. `img/tract/buildings/<building_id>.png` — по спрайту на тип постройки (20 id из спеки).
3. `docs/strongholds-v2/ART_MANIFEST.md` — таблица: файл → источник → лицензия; отбракованные варианты с причиной.

## Гейты

- Каждый файл существует, валидный PNG, разумный размер (<200KB).
- Интеграционная проба: HTML-страница-контактный лист рендерит всё через file://, скриншот без битых картинок — либо проба PIL/identify.
- Стилевая когерентность: юниты и здания одного пака/эпохи; смешение стилей — только с обоснованием в манифесте.

## Запреты

- Не трогать js/, css/, index.html (интеграция — фаза dev/art-revisit отдельно).
- Не коммитить ассеты без манифеста.
