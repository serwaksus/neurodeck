## Харнес
Напиши tools/playtest-data.cjs (каркас — tools/playtest-acceptance.cjs: step/shot, ловушка консоли). Шаги:
1. Round-trip v9 байт-в-контент (stable stringify, как acceptance 10.2): gold/strongholds/army/siege/tasks/quests(progress!)/season/hirePool.
2. Миграции: v7-фикстура (по образцу tests/storage-v8.test.js) с мусорными полями; v8-фикстура без season → v9 сеет Сезон 1 со снапшотом; битые JSON (случайные мутации валидного сейва ×20 вариантов) — приложение не падает, санитайзеры держат.
3. 5 слоёв защиты: удалить neurodeck_full_save при живом cards_backup → карточки восстанавливаются; FORGED пуст + ever_saved — не блокирует онбординг.
4. Экспорт/импорт JSON: export-json → скачать контент → импорт через file input → состояние восстановлено.
5. Две вкладки: страница A меняет золото, страница B перезагружается → видит изменение (last-write-wins).
6. Квота: забить localStorage большими ключами до отказа → saveGameState не роняет приложение.
7. Вайп: full-wipe-all → чистое состояние; new-game-keep-cards → карточки живы.
8. Фаззинг санитайзеров (node, без браузера): 100 случайных мутаций валидного state → STATE_GUARDS.* не бросают.
