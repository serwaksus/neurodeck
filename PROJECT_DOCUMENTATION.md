## 1. Обзор проекта

**NeuroDeck** — приложение, в котором геймификация трекера привычек построена вокруг RPG-механик Souls-like жанра:

- Выполняешь привычку → наносишь урон боссу, получаешь XP
- Пропускаешь привычку → босс лечится, ты теряешь HP
- HP достигает 0 → становишься «Полым» (дебафф -50% урона)
- Повышаешь ранг карточки → растут атрибуты героя
- Накапливаешь ранг-апы → открываешь новые комнаты на карте подземелья
- Побеждаешь босса → получаешь награды, появляется новый босс

**Развёртывание:** GitHub Pages → `https://serwaksus.github.io/neurodeck/`
**Платформа:** Telegram Mini App (BotFather)
**Язык интерфейса:** русский

## 4. Игровые механики

### 4.1 Карточки (Колода)

**Карточка** — основная единица привычки в игре. Каждая карточка представляет собой ежедневное задание.

**Свойства карточки:**
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | number | Уникальный ID |
| `name` | string | Название (напр. «Медитация») |
| `meta` | string | Метаданные вида `🧠 15 мин · утро` |
| `stat` | string | Привязанный стат: `str`/`end`/`int`/`cha`/`wil`/`agi` |
| `rank` | string | Текущий ранг (C → SSS) |
| `mastery` | number | Текущее мастерство |
| `masteryThreshold` | number | Порог мастерства до след. ранга |
| `streak` | number | Текущий стрик (дни подряд) |
| `totalCompletions` | number | Всего выполнений за всё время |
| `daysActive` | number | Дней с первого выполнения |
| `firstCompletedAt` | number | Timestamp первого выполнения |
| `lastCompletedAt` | number | Timestamp последнего выполнения |

**Действия с карточкой:**
- **✓ Выполнить** — даёт XP, мастерство, урон боссу, шанс лута
- **✕ Пропустить** — босс лечится, стрик обнуляется
- **✎ Редактировать** — открыть форму редактирования (long-press на мобилке)
- **🗑 Удалить** — удалить с подтверждением

**Ковка карточки** (`forgeCard()`):
- Игрок выбирает: название, стат, время суток, длительность, стартовый ранг, порог мастерства
- При создании: +10 XP, эффект частиц, звук ковки
- Карточка добавляется в начало массива `FORGED`

**3D Tilt-эффект:** карточки наклоняются в 3D при движении мыши/касании (`perspective(800px) rotateX/rotateY`).

### 4.2 Ранги и мастерство

**Прогрессия рангов (12 ступеней):**
```
C → CC → CCC → B → BB → BBB → A → AA → AAA → S → SS → SSS
```

**Цвета по рангам:**
| Базовый ранг | Цвет | Палитра |
|-------------|------|---------|
| C/CC/CCC | Серый | `#9ca3af` |
| B/BB/BBB | Синий | `#60a5fa` |
| A/AA/AAA | Фиолетовый | `#c084fc` |
| S/SS/SSS | Золотой | `#fbbf24` |

**Фразы ранг-апов:**
| Ранг | Фраза |
|------|-------|
| C | Пробуждение |
| CC | Сила крепнет |
| CCC | Воля закаляется |
| B | Путь воина |
| BB | Сталь и дух |
| BBB | Непреклонный |
| A | Мастерство |
| AA | Совершенство |
| AAA | Величие |
| S | Легенда |
| SS | Миф |
| SSS | Бессмертный |

**Механика ранг-апа:**
1. При выполнении карточки `mastery += adaptationMultiplier`
2. Когда `mastery >= masteryThreshold`:
   - Ранг повышается на ступень
   - `mastery` переносится остаток: `mastery -= masteryThreshold`
   - `masteryThreshold` увеличивается на 15%: `Math.round(threshold * 1.15)`
   - +1 очко в пул соответствующего атрибута
   - `escapeProgress += 1` (прогресс побега)
   - Запускается анимация ранг-апа
   - Через 2.2с открывается модалка **обязательного усложнения** карточки

### 4.3 Система адаптации

Адаптация — ключевой механизм против «застоя». Чем дольше карточка активна без усложнения, тем меньше XP и мастерства она даёт.

| Дней активна | Множитель | Эффект |
|-------------|-----------|--------|
| 0-6 дней | **100%** | Полная эффективность |
| 7-14 дней | **50%** | Половина XP и мастерства |
| 15+ дней | **10%** | Почти бесполезна |

**Сброс адаптации:** при редактировании карточки (изменение `meta` или `stat`) — `firstCompletedAt` и `daysActive` обнуляются, адаптация возвращается к 100%.

**Формула XP за выполнение:**
```
finalXp = round(15 * adaptationMult * (1 + (totalInt - 3) * 0.01))
```
Где `totalInt = STATS.int.value + gearBonuses.int`

**Формула мастерства за выполнение:**
```
masteryGain = adaptationMult (1.0 / 0.5 / 0.1)
```

### 4.4 Герой и атрибуты

**6 RPG-атрибутов:**

| Ключ | Название | Иконка | Эффект | Цвет |
|------|---------|--------|--------|------|
| `str` | Сила | ⚔ | Базовый урон по боссу | `#c73e4d` |
| `end` | Стойкость | 🛡 | Максимальное HP | `#60a5fa` |
| `int` | Интеллект | 🧠 | Множитель XP | `#c084fc` |
| `cha` | Харизма | 🎭 | Шанс крит. удара | `#fbbf24` |
| `wil` | Воля | 🧘 | Защита стрика при пропуске | `#34d399` |
| `agi` | Ловкость | ⚡ | (резерв) | `#fb923c` |

**Система пула атрибутов:**
- Каждый ранг-ап карточки даёт **+1 очко в пул** соответствующего стата
- При накоплении **5 очков** пула → **+1 к значению атрибута** (максимум 100)
- Это значит: **5 ранг-апов = +1 к стату**

**Формулы атрибутов в бою:**
| Атрибут | Формула |
|---------|---------|
| Базовый урон | `BASE_DAMAGE(5) + floor(sumAllStats * 0.5) + floor(gearStr / 5)` |
| Шанс крита | `min(50%, totalCha * 2%)` — крит удваивает урон |
| XP бонус | `1 + (totalInt - 3) * 1%` |
| Защита стрика | `totalWil / 300` — шанс сохранить стрик при пропуске |
| Макс. HP | `100 + (level - 1) * 5 + end.value` |

### 4.6 Боссы подземелья

**3 босса, зависящих от прогресса побега:**

| Прогресс | Босс | Иконка | Особенность |
|----------|------|--------|-------------|
| 0-39 | 🐍 Змей Лени | 🐍 | Стандартный бой |
| 40-79 | 📱 Демон Соцсетей | 📱 | Двойной урон за пропуски |
| 80-140 | 🔥 Химера Выгорания | 🔥 | **Щит**: первые 5 ударов поглощаются |

**Каждый босс имеет 3 стадии:**
| Стадия | HP | Множитель урона | Описание |
|--------|-----|-----------------|----------|
| 1 | базовый | ×1.0 | «Я жду...» |
| 2 | ×1.5 | ×1.5 | Эволюция |
| 3 | ×2.0 | ×2.0 | Финальная ярость |

**HP боссов по типам:**

| Босс | Стадия 1 | Стадия 2 | Стадия 3 |
|------|---------|---------|---------|
| Змей | 100 | 150 | 200 |
| Демон | 120 | 180 | 250 |
| Химера | 150 | 220 | 300 |

**Механика боя:**
1. **Выполнение карточки** → расчёт урона → `changeBossHp(-dmg)`
2. **Крит** (шанс от Харизмы) → урон ×2, спецэффекты
3. **Состояние Hollow** → урон ×0.5
4. **Щит Химеры** → поглощает 5 ударов (каждый удар снимает 1 заряд)
5. **HP босса = 0** → переход на следующую стадию (с 3 → казнь)

**Казнь босса (`triggerBossExecution()`):**
- Глобальная анимация смерти (3 сек)
- 300 золотых + 200 красных частиц
- Тряска экрана (25 ед., 1.5 сек)
- Награды: **+1000 XP**, 2 случайных артефакта
- Запись в `_bossKills`
- Через 3 сек — оверлей «☠ ПОВЕРЖЕН»
- Через 8 сек — **возрождение нового босса** (с 1 стадии, полный HP)

**Визуальные эффекты боя:**
- Трещины (`bossCracks`) — opacity растёт от полученного урона
- Кровь (`bossBlood`) — opacity при HP < 30%
- `hue-rotate` на спрайте — визуальное искажение от урона
- Глаза следят за курсором (`mousemove` → `translate`)

**Наказание босса (23:00 МСК):**
- Каждый день в 23:00 МСК босс наносит урон за каждую **невыполненную карточку**
- Урон = `10 × stage.dmgMult` за карточку
- Эстус защищает от наказания
- Отображается обратный отсчёт в боковой панели

### 4.7 Цели

**3 типа целей с разными наградами:**

| Тип | Иконка | Дедлайн | XP | Урон боссу | Очков пула |
|-----|--------|---------|-----|-----------|------------|
| Краткая | 🟢 | 1-7 дней | +20 | -5 HP | +1 |
| Средняя | 🔵 | 1-4 недели | +50 | -12 HP | +2 |
| Долгая | 🟡 | 1+ месяц | +120 | -25 HP | +5 |

**Создание цели:**
- Выбор типа (визуальные карточки)
- Название, описание
- Дедлайн: **дата + время** (default 23:00)
- Количество шагов (default 5)
- Привязка к стату

**Выполнение цели:**
- Кнопка «+ Шаг» — выполняет один шаг цели
- Каждый шаг: +`xp / totalSteps / 2` XP, +1 очко пула стата
- Последний шаг → автозавершение → полная награда + анимация
- Завершение: +XP, +очки пула, -HP боссу, частицы

**Провал цели (`checkGoalDeadlines()`):**
- Проверка каждые **30 секунд**
- При истечении дедлайна:
  - Цель помечается `failed: true`
  - Удвоенный урон герою: `dmg * 2`
  - Тряска экрана, кровавый дождь
  - Toast «💀 Цель провалена!»

**Обратный отсчёт:** в карточке цели отображается время до дедлайна с цветовой индикацией:
- `safe` (зелёный) — > 24ч
- `warning` (жёлтый) — < 24ч
- `critical` (красный) — < 1ч или просрочено

### 4.10 Система Hollow / Искупление

**Становление Полым:**
- Если HP героя падает до 0 от наказания босса
- Герой не умирает, а становится **Полым**
- Эффекты:
  - Титул: «Полый, потерявший цель»
  - Аватар получает класс `.hollow` (визуальное искажение)
  - **Урон по боссу -50%**
  - Появляется **полоса искупления** (3 сегмента)

**Искупление:**
- Нужно **3 идеальных дня подряд** (все карточки выполнены, 0 пропусков)
- Каждый идеальный день заполняет 1 сегмент
- При 3/3: возвращение человечности, HP = 50% от максимума
- Пропуск в любой день — счётчик обнуляется

### 4.11 Эстус

**Фляги Эстуса** — защита от наказания босса.

- **3 фляги** в месяц (восстанавливаются 1-го числа каждого месяца)
- 1 использование в день
- При выпивании: босс **не наносит урон** в эту ночь (23:00 МСК)
- Toast: «🧪 Эстус выпит»

## 5. Ежедневные циклы

### Часовой пояс
Все временные расчёты — по **Москве (UTC+3)**.

### Таймеры

| Интервал | Функция | Описание |
|----------|---------|----------|
| 60 сек | `checkDailyReset()` | Проверка смены дня (23:00 МСК) |
| 60 сек | `updatePunishCountdown()` | Обновление обратного отсчёта наказания |
| 30 сек | `checkGoalDeadlines()` | Проверка дедлайнов целей |

### `checkDailyReset()` — Ночная обработка

Срабатывает при смене дня (по МСК):

1. **Наказание босса:**
   - Подсчёт невыполненных карточек за прошедший день
   - Если есть невыполненные и не выпит Эстус:
     - `HERO.hp -= count × 10 × stage.dmgMult`
     - Кровавый дождь, тряска, спецэффект босса
     - Если HP ≤ 0 → состояние Hollow

2. **Подсчёт идеальных дней:**
   - `dailyCompletions > 0 && dailySkips === 0` → `consecutivePerfectDays++`
   - Иначе → сброс до 0

3. **Проверка искупления:**
   - Если Hollow и 3 идеальных дня подряд → восстановление

4. **Сброс дневных счётчиков:**
   - `dailyCompletions = 0`
   - `dailySkips = 0`
   - `estusUsedToday = false`
   - `chimeraShield = 5` (перезарядка щита Химеры)

5. **Месячный сброс Эстуса:**
   - При смене месяца: `estus = 3`

6. **Обновление `daysActive`** всех карточек

## 7. Синхронизация данных

### 3 способа + авто-сохранение

#### 7.1 Telegram CloudStorage (автоматически + вручную)

**Автосохранение** (`autoCloudSave()`):
- Срабатывает при каждом `saveGameState()`
- Throttle: **не чаще, чем раз в 2 минуты**
- Чанкинг по **4096 символов** (`CLOUD_MAX_CHUNK`)
- Ключи: `nd_meta` (метаданные) + `nd_0`, `nd_1`, ... (чанки)

**Ручное сохранение** (`saveToCloud()`):
- Без throttle
- Таймаут 10 сек (если облако не ответило — предложение использовать файл)

**Загрузка из облака** (`loadFromCloud()`):
- Чтение `nd_meta` → чтение N чанков → сборка JSON → `applySyncData()`

**Восстановление при потере** (`tryCloudRecovery()`):
- Если `localStorage` пуст, проверяет облако
- При наличии данных — диалог с информацией о сохранении
- При подтверждении — восстановление + `location.reload()`

#### 7.2 Share Link

- `generateShareLink()`: `buildSyncData()` → JSON → `btoa(encodeURI())` → `#hash`
- Копирование в буфер обмена или `navigator.share()`
- `importFromHash()`: при загрузке страницы проверяет `location.hash`

#### 7.3 Файл `.ndsync`

- `downloadSyncFile()`: JSON → Blob → `.ndsync` файл
- `importSyncFile()`: FileReader → JSON parse → `applySyncData()`

#### 7.4 JSON Export

- `exportJson()`: отдельный экспорт для просмотра/бэкапа
- Файл: `neurodeck-export-YYYY-MM-DD.json`

#### `applySyncData(data, skipRender)`

Единая функция применения данных со всеми guard'ами:
- Санитизация HERO (HP/XP/level в допустимых пределах)
- Санитизация STATS (value 0..max, attributePoints ≥ 0)
- Санитизация FORGED (default rank/mastery/threshold)
- Полный ре-рендер всех UI
